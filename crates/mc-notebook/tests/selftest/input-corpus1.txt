# Math input corpus, part 1 (round 32): fractions in exponents, nested roots, indexed and scripted names, Greek and
# aliases. Every formula is typed through the keyboard into a new cell at the end, then checked: its box tree, the
# linear text it lowers to (what Copy gives), its value, and that its output copied and pasted as math reads as the
# same text. Driven by tests/input_selftest.rs.
size 1000 700
ppp 1
theme light
new

# ---- fractions in exponents ----
formula frac-exp/gauss
keys Ctrl+End "e" Ctrl+6 "-x" Ctrl+6 "2" Ctrl+Space Ctrl+/ "2"
expect boxes "(e^-((x^2)/2▮))"
expect linear "e^(-(x^2/2))"
eval
expect output "exp((-1/2)*x^2)"
roundtrip
